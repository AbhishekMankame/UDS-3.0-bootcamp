# Create conda environment
Syntax : conda create -n <name of environment> python=3.xx
Example : conda create -n UDS3 python=3.12

# Activating the conda environment
Syntax : conda activate <name of environment>
Syntax (Unix/Mac-OS) : source activate <name of environment>
Example : conda activate UDS3
Example (Unix/Mac-OS) : source activate UDS3

# Run python file (.py) using conda environment python
Step-1 : Go to the location where file is present
Step-2 : Python <file-name>.py
